# TFR 中国谈判（中蒙 + 中俄）

> **The Fire Rises** 模组子模组 — 中华人民共和国对蒙古的和平统一谈判 & 对俄罗斯的远东领土购买谈判

---

## 项目一览

本子模组包含**两套独立的外交谈判系统**：

| 谈判 | 对象 | 目标 | 机制 |
|:----|:----|:----|:----:|
| 🇨🇳🇲🇳 **中蒙谈判** (CMRN) | 蒙古 (MON) | 和平统一 5 省 | 三轮回合制 · 双向决策 · 结算公式 |
| 🇨🇳🇷🇺 **中俄谈判** (CRN) | 俄罗斯 (SOV) | 赎回外东北 + 图瓦 8 省 | 绝望度驱动 · 固定顺序购买 · 100 天限时 |

---

## 📖 项目简介

**TFR 中国谈判** 是《The Fire Rises》模组的子模组，为中华人民共和国（PRC）提供两条外交谈判路线：与蒙古（MON）的和平统一谈判，以及与俄罗斯（SOV）的远东领土购买谈判。

在 TFR 的世界观中，台海战争胜利后，中国国力和国际影响力大幅提升，为彻底解决北方历史遗留问题提供了难得的战略窗口期。本子模组从**两个方向**入手：

> **🇨🇳🇲🇳 中蒙方向：** 通过三轮回合制外交谈判，综合运用经济合作、文化交流、基建投资、政治施压等手段，争取蒙古民众与政府的统一意愿。若谈判成功则和平统一并建立蒙古自治区；若谈判破裂则发动征服战争，战后需经过军管治理最终实现统一。
>
> **🇨🇳🇷🇺 中俄方向：** 趁俄罗斯深陷欧陆战争泥潭之际，通过外交施压和经济赎买，分 8 省固定顺序赎回外东北 + 图瓦的历史领土。俄罗斯的绝望度越高，可购买的省份越多。

- 蒙古仍作为独立国家存在

## 🎯 谈判机制详解

### 基础数值

| 变量 | 范围 | 说明 |
|------|------|------|
| `TFR_CMRN_unification_tendency` | 0 ~ 1 | **统一倾向** — 蒙古国内对与 PRC 统一的支持度。初始 0.30 |
| `TFR_CMRN_prc_influence` | 0 ~ 1 | **外交影响力** — PRC 在蒙古的影响力积累。初始 0.15 |
| `TFR_CMRN_hidden_will` | — | **隐藏意愿** — 最终结算判定值。由公式动态计算 |

### 结算公式

```
hidden_will = prc_influence × (PRC总工厂数 × 0.008) × unification_tendency

hidden_will > 1  →  和平统一（吞并 + 加核心 + 蒙古自治区）
hidden_will ≤ 1  →  谈判破裂，PRC 对 MON 宣战（征服战争）
```

> 💡 **策略提示：** PRC 的工业实力（工厂数）直接影响结算权重。因此前期种田积累国力对谈判成功率有很大帮助。

### 轮次规则

| 特性 | 说明 |
|------|------|
| **每轮时长** | 60 天（由 `days_mission_timeout` 控制） |
| **PRC 行动** | 每轮有多个一次性决议 + 1 个可重复决议（外交照会/经济激励/最后通牒） |
| **MON 回应** | MON 每轮可回应次数受 PRC 本轮行动次数限制（`MON_actions < PRC_actions`） |
| **自动推进** | 计时器超时 → 自动进入下一轮 |
| **提前宣战** | PRC 可随时通过「对蒙古宣战」决议中断谈判 |

## 🏁 结算与结果

### 路径 A：和平统一（`hidden_will > 1`）

1. **吞并蒙古** — `annex_country = { target = MON transfer_troops = yes }`
2. **添加核心** — 蒙古 5 省全部获得 `add_core_of = PRC`
3. **成立蒙古自治区** — 触发 `TFR_CMRN_setup_mongol_autonomy`
4. **自治区修正**（`TFR_CMRN_mongol_autonomy`，永久持续）：

| 效果 | 数值 |
|------|:----:|
| 建筑速度 | +15% |
| 适役人口 | +3% |
| 建筑槽位 | +1 |
| 当地补给 | +8% |
| 动员速度 | +15% |

5. **新闻事件** — `TFR_CMRN.5` 和平统一新闻

### 路径 B：征服战争（`hidden_will ≤ 1` 或 PRC 主动宣战）

1. **PRC 对 MON 宣战** — `declare_war_on = { target = MON type = annex_everything }`
2. **战争决议确认** — `TFR_CMRN.7` 国家事件（确认宣战）
3. **战后军管流程**（MON 被消灭后自动触发）

### 战后军管治理流程

战争路径下，MON 被消灭后，进入 5 省军管治理阶段。流程严格串行：

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│ 省整肃×5  │ →  │ 重建基础  │ →  │ 恢复经济  │ →  │ 民族和解  │ →  │ 解除军管  │
│ 75 PP/省  │    │ 设施     │    │ 生产     │    │          │    │          │
│           │    │ 50 PP    │    │ 75 PP    │    │ 50 PP    │    │          │
│ mz=-0.40  │    │ -0.26667 │    │ -0.13334 │    │ 0        │    │ 自治区!  │
└──────────┘    └──────────┘    └──────────┘    └──────────┘    └──────────┘
```

**军管区 dynamic_modifier**（`TFR_CMRN_military_zone`）：

| 效果 | 数值（初始） |
|------|:-----------:|
| 建筑速度 | -40% |
| 当地人力 | -70% |
| 当地工厂产出 | -50% |

> 随着重建步骤推进（`mz_build` 变量从 -0.40 逐步增加到 0），debuff 逐步减轻。最终解除军管后，与和平统一路径一样获得`蒙古自治区`的永久 buff。

**军管治理总成本：** 5×75 + 50 + 75 + 50 = **550 PP**

## 🇨🇳🇷🇺 中俄谈判系统（TFR\_CRN）

> **目标：** 趁俄罗斯深陷欧陆战争泥潭之际，以外交施压 + 经济赎买方式，分阶段赎回外东北 + 图瓦共 8 个历史领土省份。
>
> **核心机制：** 100 天限时谈判窗口 | SOV 绝望度（0-100）驱动可购买顺序 | 3 种施压大棒 | 8 省固定顺序购买

### 背景设定

台海战争后，PRC 国势强盛。此时俄罗斯（SOV）正深陷**第一次/第二次欧陆战争**，东西两线承受巨大压力。PRC 抓住这个历史性战略窗口，以外交与经济手段向俄方提出领土赎回谈判。

> 📜 **历史参照：** 8 省对应的是 19 世纪《瑷珲条约》《北京条约》等不平等条约中割让给沙俄的外东北领土 + 唐努乌梁海（图瓦）。

### 机制概览


### 绝望度系统（SOV Desperation）

绝望度是驱动中俄谈判的核心数值，范围 **0 ~ 100**。每次 PRC 打开谈判面板或完成一次购买后自动重算。

| 来源 | 计算方式 | 最大贡献 |
|:----|:--------|:--------:|
| **战争状态** | SOV 正处于战争中 | +10 |
| **投降倾向** | `surrender_progress × 0.4` | 0~40 |
| **战争伤亡** | `has_casualties_war_support × 0.3` | 0~30 |
| **稳定度低下** | `(100% - stability) × 100`，超过 20 则钳位 | 0~20 |
| **谈判天数** | 已过天数 × 0.5，超过 50 则钳位 | 0~50 |
| **大棒施压** | 外交照会(+10) / 经济制裁(+15) / 边境军演(+20) | 0~45 |

> 💡 **策略提示：** 绝望度主要靠 SOV 自身战况驱动——SOV 在欧陆战争中越被动，投降倾向越高，PRC 能买到的省份就越多。三种大棒作为补充手段，冷却期递进（20/30/45 天），边境军演虽效果最大但会推高世界紧张度和降低 SOV 稳定。

### PRC 施压手段（大棒）

| 决议 | PP | 冷却 | 绝望度+ | 副作用 |
|:----|:--:|:----:|:-------:|--------|
| 外交照会施压 | 25 | 20 天 | +10 | 无 |
| 经济制裁威胁 | 50 | 30 天 | +15 | SOV 贸易惩罚 `trade_opinion_factor = -0.3` |
| 边境军事演习 | 75 | 45 天 | +20 | 世界紧张度 +0.5，SOV 稳定度 -3% |

> 三种大棒共享同一谈判窗口（100 天），合理规划冷却期以最大化绝望度积累。
