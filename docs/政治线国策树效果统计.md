## 互斥 / 三选二说明(不可同时全取)

1. **climax ↔ long_march 二选一**(地区整合前置):`PRC_nl_socialist_construction_climax`(社会主义建设高潮)与 `PRC_nl_long_march_plan`(长征计划)按树形二选一。climax 贡献 `mic 收入增长+0.1 / 开支增长+0.05 / 个人价值因子+0.1`;走 long_march 分支则无这 3 键(其奖励走事件/决议)。
2. **unite_efforts 前置三选一**:**党代表什么 / 促进公众参与 / 数字监督人民** 三个政治分支国策中进三选二结构(树形只允许其一进 `unite_efforts_with_unity`),分支贡献:
   - 促进公众参与(`promote_public_participation_politics`):RPD 动员+0.15、情报机构+2、民用情报-0.15
   - 数字监督(`digital_supervision_of_the_people`):RPD 稳定+0.05、开支-0.05、社会发展+0.005
   - 党代表什么(`what_does_party_represent`):无动态变量(事件/决议奖励)
3. **基层三路线**(重建无产阶级专政前置,RPD 段):`PRC_grassroots_lost / _win / _ord` 三选一路线 flag,由决策链选择,影响 RPD 分支开放。
4. 表中「必达链」= 不含上述互斥分支的国策累计;「分支」值= 走对应路线才可得的增量。

> 注意:互斥/三选组本身不写在 available 的 NOT 计数里(经全树扫描确认),而是通过「前置 OR + 事件 flag」实现,故上表按路径拆开标注。
